# 📝 TaskFlow - To-Do List

TaskFlow is a simple and responsive To-Do List web application built with HTML, CSS and JavaScript.

## 🚀 Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Filter tasks
- Clear completed tasks
- Store tasks using LocalStorage
- Responsive design
- Keyboard support with Enter
- Basic HTML escaping for user input

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- LocalStorage
